# Martian Zoo site

This repository publishes the separate Martian Zoo website at
https://www.martianzoo.dev/ using GitHub Pages. It contains plain HTML and image
files, with no site generator or content management system.

The initial images were copied from
[`kevinb9n/martianzoo`](https://github.com/kevinb9n/martianzoo). That repository
also serves the personal-site image URL at
`https://kevinb9n.site/martianzoo/images/classes/`. The two sites publish
independently; updating images in either repository does not update the other.
